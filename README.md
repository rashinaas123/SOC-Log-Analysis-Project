# SOC Log Analysis and Threat Detection

## Objective
To analyze authentication logs and
identify repeated failed login attempts.

## Tools Used
- Kali Linux
- Linux Commands
- Python 3

## Project Features
- Log analysis
- Failed login detection
- IP address counting
- Automated report generation
